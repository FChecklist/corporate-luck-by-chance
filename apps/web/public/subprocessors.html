Sub-processors

The providers that help us run Corporate Luck by Chance.

Providers

  • Cloudflare: Hosting, database, network. The website runs on Cloudflare’s global network. The database is kept in Cloudflare’s Asia-Pacific region.
  • Resend: Sending e-mail to organizers. United States, as published by Resend.
  • Google: Optional “Continue with Google” sign-in for organizers and Hosts (only if you press the button). United States, as published by Google.
  • Razorpay: Organizer payments (never players). India, as published by Razorpay.
  • IT Services payment service (itservices-rajat-agarwal.pages.dev): our own central payment service. It starts the Razorpay payment and records each payment for the organizer’s invoice and our accounts (never players). It runs on Cloudflare.
  • GitHub: Runs our scheduled jobs, including the timer that deletes data on time, and keeps a protected copy of the payment records (organizers’ payments only, never players). United States, as published by GitHub.

Also used

  • drand: a public random beacon, used only if a public beacon number is added to a game’s sealed seed. We send it no personal data.
  • YouTube (privacy mode): only if an organizer adds a brand video moment. The player’s phone contacts YouTube.
  • Google Sign-In: only if an organizer or Host presses Continue with Google. Google confirms the e-mail; we keep that address and nothing else. Players never meet Google.

Changes

  • We update this page when the list changes.
