**PDFs and e-mail.**
- Report PDF, people-part PDFs and invoice PDF now carry the Luck by Chance badge, drawn as vector shapes (no picture inside, the files stay small). The PDF gold is the kit's marigold.

9. **41 older files** (`app.css`, `z.css`, `guide.js` ...) have no `?v=`. The built `_headers` make css and js `no-cache`, so a changed file is fetched again. Not changed.
10. **The old `site/` folder** (a "coming soon" site, never deployed) is only kept in step for the four legal pages.
